오늘의 할 일 - 설치형 웹앱(PWA)

[온라인에 올리기 - 무료, 3분]
방법 A) Netlify Drop (가장 쉬움)
 1. https://app.netlify.com/drop 접속 → 무료 가입(구글/깃허브 계정 가능)
 2. 압축을 푼 이 폴더(pwa)를 화면에 끌어다 놓기
 3. 생긴 주소(예: xxxx.netlify.app)를 친구에게 공유
    - Site settings → Change site name 에서 주소 이름 변경 가능

방법 B) GitHub Pages
 1. github.com 에서 새 저장소(Public) 만들기 → 이 폴더 파일 전부 업로드
 2. Settings → Pages → Branch: main / root → Save
 3. https://아이디.github.io/저장소이름/ 주소를 공유

[폰에 앱으로 설치]
 - 아이폰: Safari로 주소 열기 → 공유(□↑) → 홈 화면에 추가
 - 안드로이드: Chrome으로 열기 → ⋮ → 앱 설치(홈 화면에 추가)

[알아둘 것]
 - 할 일은 각자 폰에만 저장돼요(서버 없음, 서로 안 보임). 
 - 폰을 바꾸거나 PC로 옮길 땐 설정(⚙) → 백업 내보내기 → 새 기기에서 가져오기
 - 앱을 고쳐서 다시 올리면 다음 실행 때 자동으로 새 버전이 적용돼요.
